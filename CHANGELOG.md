# Changelog

All notable changes to SubZero are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0]

### Added

- Server authorization and authenticated scheduled jobs.
- Automated CI, CodeQL analysis, and dependency update configuration.
- Portable non-root Next.js container with health and readiness endpoints.
- Structured server logs and request correlation for critical paths.
- Versioned release validation and deployment operations documentation.

The pre-DevOps `subzero-pre-devops-v1` tag is a historical baseline, not a SemVer release.
